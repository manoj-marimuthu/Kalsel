## Kalsel

A compiler written from scratch in C that compiles to x86 Intel assembly and
produces an executable for the program.

## Example

for now, it only allows writing operations and numbers,
the result of each line is autoprinted. Example - 

```kalsel
1 + 2
10 - 90
40 + 3
10 / 3 + 3
```

## Features

- +,-,*,/
- all integer constants are taken as 64-bit integers
